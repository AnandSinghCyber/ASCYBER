Linux Basics for Security Professionals

By Anand Singh Updated August 2026

Windows is great for gaming, and macOS is great for design. But the internet runs on Linux. From massive web servers to the router in your living room, Linux is everywhere. If you want to master cybersecurity, you must master the Linux command line.

1. The Linux File System Hierarchy

Unlike Windows, which uses C:\ and D:\ drives, Linux treats everything as a unified tree structure starting at the root (/).

  • / : The Root directory. Everything starts here.
  • /bin : Essential user binaries (commands like ls, cat).
  • /etc : System configuration files (this is where hackers look for misconfigurations).
  • /home : Personal directories for users (e.g., /home/anand).
  • /var : Variable data, like system logs (/var/log) and web server files (/var/www/html).

2. Understanding Permissions

Linux is a multi-user environment, so security is baked into the file system. Every file and directory has permissions that control who can Read (r), Write (w), or eXecute (x) it.

Permissions are broken into three categories:

  1. User (u): The owner of the file.
  2. Group (g): Users who are in the file's group.
  3. Others (o): Everyone else.
bash
$ ls -l
-rwxr-xr-- 1 anand admin 1024 Aug 19 script.sh

In the example above, -rwxr-xr-- means the owner (anand) can read, write, and execute. The group (admin) can read and execute. Everyone else can only read.

3. Essential Commands Cheat Sheet

You need to be comfortable navigating the terminal without a mouse. Memorize these:

pwd          # Print Working Directory (where am I?)
ls -la       # List all files, including hidden ones, with permissions
cd /etc      # Change Directory to /etc
cat file.txt # Read the contents of file.txt to the screen
grep "error" # Search for the word "error" in text or output
sudo command # Execute a command with Root (Superuser) privileges
chmod +x app # Make a file executable
