Networking Fundamentals for Hackers

By Anand Singh Updated August 2026

You cannot hack a system if you don't know how to reach it. Networking is the study of how computers communicate. It is arguably the most important foundational skill for any cybersecurity professional.

1. IP vs MAC Addresses

Every device connected to a network needs a way to be identified.

  • IP Address (Internet Protocol): Think of this like your home address (e.g., 123 Main St). It tells the internet where to send data. It can change if you move to a different coffee shop. Example: 192.168.1.5
  • MAC Address (Media Access Control): Think of this as your Social Security Number. It is physically burned into your computer's network card at the factory and (theoretically) never changes. Example: 00:1A:2B:3C:4D:5E

2. The OSI Model

The Open Systems Interconnection (OSI) model is a conceptual framework used to describe how data travels over a network from one computer to another. It has 7 layers:

  1. Application (Layer 7): What you see (Web browsers, HTTP, FTP).
  2. Presentation (Layer 6): Data translation and encryption (JPEG, TLS).
  3. Session (Layer 5): Manages connections and sessions between apps.
  4. Transport (Layer 4): How data is sent. TCP (reliable, checks for errors) vs UDP (fast, streams video, no error checking).
  5. Network (Layer 3): Routing data across the internet using IP Addresses. (Routers live here).
  6. Data Link (Layer 2): Local network communication using MAC addresses. (Switches live here).
  7. Physical (Layer 1): The actual cables, radio waves, and electricity.

Hacker Tip: When a DDoS attack happens, it targets a specific layer. A "Volumetric Attack" hits Layer 3 or 4, overwhelming the router. An "Application Attack" hits Layer 7, overwhelming the web server software.

3. Essential Ports and Protocols

If an IP address is a house, a Port is a specific door or window on that house. There are 65,535 possible ports. Different services run on different ports:

Port 21: FTP (File Transfer - Unsecure)
Port 22: SSH (Secure Shell - Remote access)
Port 53: DNS (Domain Name System - Converts google.com to an IP)
Port 80: HTTP (Web Traffic - Unsecure)
Port 443: HTTPS (Web Traffic - Encrypted/Secure)
Port 3389: RDP (Remote Desktop Protocol)

When you use a tool like Nmap, you are basically "knocking" on all 65,535 doors of a house to see which ones are unlocked and who answers the door.
